# Observations

A shared log of interesting findings, flow paths, and insights noticed while using mindVisualizer. The goal is an open, informal record — not formal results — that helps build a collective mental model of how the resting brain might be organizing itself.

If you find something worth sharing, add it here and open a PR.

---

## How to contribute

- Describe what you did (mode, probe placement, perturbation, etc.)
- Describe what you observed
- Add any interpretation — even a rough intuition is useful
- You don't need to be certain. Speculation is welcome as long as it's labeled as such.
